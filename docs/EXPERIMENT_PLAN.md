# 后续研究与面试解释

## 当前已完成

模拟 Q/K/V 下的四种分数、两档位宽、六种保护配置；可重复 CSV 导出；数值正确性测试；真实 Qwen 采集入口与随机小模型接口验证。

## 下一阶段

1. 在 Qwen3-1.7B 的事实提取、跨段关联、代码解释三类短任务中采集多层注意力；每类先固定 10 条提示词，记录模型版本、prompt 和随机设置。只采集注意力，暂不改变缓存。
2. 在固定 prompt 候选集上观察 Top-K 重合率、近期 token 注意力比例和分数随 token 年龄的变化；比较逐层轨迹，避免将平均值当成所有层的普遍规律。
3. 在 5 个随机种子的合成 Q/K/V 上，对 alpha={0.1,0.2,0.5}、window={4,8,16} 做参数实验；报告分布和方差，不只挑最优单次结果。
4. 真实缓存量化需要进一步实现并验证 Pre-RoPE 采集、GQA 映射、真实低比特打包和元数据成本，再测量任务正确率或 PPL、峰值内存和逐 token 延迟。不要用当前离线误差替代这些指标。

## 可以解释的设计决策

* 为什么不只用累计注意力：历史长的 token 会积累更多分数，阶段切换后可能响应较慢。
* 为什么选前一步的分数：当前查询的注意力只有计算后才能知道，用它先保护缓存会形成先知决策。
* 为什么用 NaN：token 未出生是“没有观测”，不是“注意力为零”。
* 为什么保护范围不参与量化尺度：已用全精度保留的异常值没有必要继续扩大低比特组的区间。
* 为什么不能写显存降低 75%：反量化参考实现仍存 float，真实打包、尺度、索引与保护位置都有额外成本。
* 为什么块统计不是 PagedAttention：统计逻辑位置没有完成物理页管理、缓存共享及专用内核。

## 实验复核清单

保持对照的全精度 token 预算相等；明确离群值额外开销；分开报告合成与真实数据；保留原始 CSV；未完成的模型实验不写成已取得的成果。
